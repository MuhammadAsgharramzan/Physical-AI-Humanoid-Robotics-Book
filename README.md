# Physical AI & Humanoid Robotics Book

This repository contains the source for a comprehensive book on Physical AI and Humanoid Robotics, designed to be accessible to students, hobbyists, and early-stage robotics learners without requiring advanced mathematics.

## Structure

- `content/` - Main book content in Markdown format
- `media/` - Images, diagrams, and other media assets
- `research/` - Research notes and source materials
- `drafts/` - Draft chapters and content
- `backend/src/` - Backend services for RAG chatbot
- `frontend/src/` - Frontend customizations
- `vector/` - Vector database configurations
- `specs/` - Specification and planning documents

## Features

- English and Urdu bilingual explanations
- 10+ diagrams and conceptual illustrations
- 20+ credible references (IEEE, ACM, arXiv, robotics textbooks)
- RAG chatbot for interactive learning
- Docusaurus-based documentation site

## Building

The book content is written in Markdown and can be compiled to PDF and ePub formats.
