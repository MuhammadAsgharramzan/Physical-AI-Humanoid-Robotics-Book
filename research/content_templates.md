# Content Templates for Consistent Book Formatting

## Module Template Structure

### Standard Module Format
```markdown
---
title: "Module X: [Module Title]"
description: "Brief description of the module content"
---

# [Module Title]

## Introduction

Brief introduction to the module topic and what readers will learn.

## [Section 1 Title]

Content for the first section...

### Key Concepts
- Concept 1
- Concept 2
- Concept 3

## [Section 2 Title]

Content for the second section...

### Technical Details
- Detail 1 [1]
- Detail 2 [2]
- Detail 3 [3]

## Summary

Brief summary of the module content and connection to next module.

## References

[1] A. B. Author, "Title of paper," *Journal Name*, vol. X, no. X, pp. XX-XX, Year.
[2] A. B. Author, *Book Title*, Publisher, Year.
[3] A. B. Author, "Title," Organization. [Online]. Available: URL. [Accessed: Date].
```

## Content Formatting Standards

### Headings Hierarchy
- `#` Main module title
- `##` Section titles
- `###` Subsection titles
- `####` Detailed subsections

### Text Formatting
- **Bold** for important terms
- *Italic* for technical terms on first use
- `Code` for technical commands or variables

### Lists
- Use bullet points for concepts and features
- Use numbered lists for processes and steps
- Use checklists for requirements and tasks

### Citations
- In-text citations: [1], [2], [3]
- Place before punctuation when possible
- Use consecutive numbering within each module

## Technical Content Standards

### Code Examples
```python
# Code example with clear comments
def example_function():
    # Brief explanation of what this does
    pass
```

### Diagram References
- All diagrams should have alt-text descriptions
- Reference diagrams in text: "As shown in Figure X..."
- Include accessibility descriptions for visual elements

### Mathematical Expressions
- Minimize mathematical complexity as per requirements
- Use verbal explanations instead of equations when possible
- Include visual analogies for complex concepts

## Bilingual Formatting

### English-Urdu Structure
```markdown
## English Section

English content here...

## Urdu Equivalent

Urdu content here...
```

### Technical Term Format
- Technical term (Urdu equivalent)
- Example: actuator (ایکٹوایٹر)

## Quality Checkpoints

### Before Finalizing Content
- [ ] All technical claims verified against sources
- [ ] Citations properly formatted in IEEE style
- [ ] Bilingual content synchronized
- [ ] Terminology consistent with dictionary
- [ ] Content within word count limits
- [ ] Accessibility considerations addressed

## Module Consistency Standards

### Standard Sections in Each Module
1. Introduction with learning objectives
2. Main content with technical details
3. Key concepts summary
4. Practical examples or case studies
5. Connection to next module
6. References and further reading

### Content Depth Guidelines
- Beginner-friendly explanations
- Technical depth appropriate for target audience
- Balance between accessibility and accuracy
- Optional advanced details clearly marked
