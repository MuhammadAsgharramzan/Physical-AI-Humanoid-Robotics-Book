# Embodied Cognition Diagram

## Diagram Title: Embodied Cognition - Mind-Body-Environment Interaction

### Description:
This diagram illustrates the embodied cognition framework, showing how cognitive processes are shaped by the interaction between the mind, body, and environment, contrasting with traditional symbolic AI approaches.

### Diagram Elements:
1. **Traditional Symbolic AI**:
   - Input: Abstract symbols
   - Processing: Symbol manipulation
   - Output: Abstract symbols
   - Isolated from physical world

2. **Embodied Cognition**:
   - Input: Sensory information from environment
   - Processing: Mind-body integration
   - Output: Physical actions
   - Continuous interaction with environment

3. **Key Components**:
   - Body as cognitive tool
   - Environment as cognitive resource
   - Action-perception cycle
   - Physical grounding of concepts

### Purpose:
To visually demonstrate the fundamental difference between traditional symbolic AI and embodied cognition, highlighting how the body and environment contribute to intelligence.
